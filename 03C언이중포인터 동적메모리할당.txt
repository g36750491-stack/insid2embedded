C언어나 C++에서 이중 포인터(**)를 사용해 2차원 배열을 동적 메모리 할당하는 구조는 
행(Row)의 주소들을 저장하는 1차원 포인터 배열을 먼저 할당하고, 
각 행마다 실제 데이터가 들어갈 1차원 배열을 각각 할당하는 방식입니다
r1={1,2,3,4,}
r2={5,6,7,8}
r3={9,10,11,12}

1. 메모리 구조의 핵심 개념이중 포인터 (int **pp): 
각 행의 시작 주소(포인터)들을 모아놓은 배열의 주소를 가리킵니다.
1단계 (행 할당): 세로 크기(Row)만큼 int* (포인터) 타입의 메모리를 할당합니다.
2단계 (열 할당): 반복문을 돌며 가로 크기(Col)만큼 int 타입의 메모리를 각 행에 연결합니다

#include <stdio.h>
#include <stdlib.h>

int main() {
    int rows = 3; // 행 개수
    int cols = 4; // 열 개수
    int **arr;

    // 1단계: 행(Row) 포인터 배열 할당
    arr = (int **)malloc(rows * sizeof(int *));

    // 2단계: 각 행마다 열(Col) 메모리 할당
    for (int i = 0; i < rows; i++) {
        arr[i] = (int *)malloc(cols * sizeof(int));
    }

    // 값 사용 예시
    arr[0][0] = 10;
    printf("%d\n", arr[0][0]);

    // 메모리 해제 (할당의 역순으로 진행)
    // 1. 각 행의 열 메모리 해제
    for (int i = 0; i < rows; i++) {
        free(arr[i]);
    }
    // 2. 행 포인터 배열 메모리 해제
    free(arr);

    return 0;
}

3. 장점과 단점장점: 각 행의 길이를 서로 다르게 만드는 가변(Ragged) 2차원 배열을 구현할 수 있으며, 
행 단위 제어가 편합니다.
단점: 메모리가 물리적으로 연속되지 않고 흩어져 있어 캐시 적중률(Cache Hit Rate)이 떨어질 수 있고,
 malloc과 free를 여러 번 호출해야 하므로 구현과 해제가 번거롭습니다.
혹시 메모리를 해제하는 순서나 단일 malloc으로 연속된 2차원 배열을 만드는 방법도 함께 설명이 필요하신가요?
